## Format

Enable `markdown`, `syntax`, or `diff` on the `wove` dependency. Each feature
adds a module that produces ordinary `RichText` elements. Parse when source
content changes, then attach or update that element in the tree.

```toml
wove = { git = "https://github.com/arocomputer/wove", branch = "main", features = ["markdown", "syntax", "diff"] }
```

These features are independent and disabled by default. They also work with
`default-features = false` for headless rendering. Applications that supply their
own styled text do not need the parsing dependencies.

`wove::markdown::render` accepts a `Palette` of complete terminal styles. `wove::syntax::Highlighter` accepts
a reusable Syntect syntax set and application-selected theme. `wove::diff::render` accepts
separate base, addition, and deletion styles. Cargo includes each parsing dependency only when its feature is enabled.

Markdown is currently linear text layout. HTML remains literal text. Link text
opens its destination in terminals with hyperlinks, and the destination is also
shown unless the text already is the destination. Markdown tables are not implemented. Highlighted spans carry no
background; fill the container with the theme's background to show it.

## Keymaps

Add `wove-keymap` separately for command bindings and key sequences. Core owns
input events and focus; the keymap package adds command matching and timeouts.

```toml
wove-keymap = { git = "https://github.com/arocomputer/wove", branch = "main" }
```

`wove-keymap::Keymap` maps sequences of `Stroke` values to application commands.
Bindings can be global or scoped to an element ID. Pass focus ancestry in order
from the focused element to the root. The nearest scope wins; newer bindings win
within a scope.

An exact binding that also begins a longer sequence waits for the timeout. Pass
the current monotonic time to `feed` with each stroke, and call `expire` when the
pending deadline arrives without one. When the deadline passes or a stroke does
not continue the sequence, the longest exact binding typed so far runs and the
strokes after it are replayed. `expire` returns the commands that became final.
`feed` returns them in `Match::Flushed` with the stroke's own result; execute the
commands in order, then handle the result. Applications own execution and scheduling.
Clear pending sequences when focus changes, and remove a scope when its element
is destroyed.
