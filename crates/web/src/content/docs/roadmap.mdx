Wove is early development software. Version 0.0.1 is not a stable release.

## Implemented

- Persistent elements, flex and grid layout, focus, and bubbling input.
- Grapheme-aware single-line and multiline editing, selection, and undo records.
- Styled spans, word wrapping, tables, and lists that request only visible rows.
- Separate Markdown, syntax highlighting, diff, and keymap packages.
- Public-key SSH applications with separate state per connection.
- Dioxus reconciliation and an asynchronous terminal runner.
- Full-screen main and alternate buffers, suspension, and resumption.
- Headless frames, recording, explicit clocks, PTY checks, and optional local timing checks.

## Remaining work

Text storage still uses a String. Large-document editing needs measured storage
and indexing work. Multiline editing follows logical lines and does not soft-wrap.
Selection with the mouse, clipboard integration, and richer terminal capability
handling remain unfinished.

Changed frames reuse storage but still paint the complete tree. Sparse painting
needs overlap and clipping tests before it can replace that behavior. Rendering
and input compatibility need broader terminal testing, especially on Windows.

Markdown uses linear block layout. Tables in Markdown, clickable links, images,
embedded terminals, audio, and 3D integration are not implemented. These
should remain optional packages when introduced.

The website currently provides only documentation infrastructure. Site design
and hosting are deferred.
